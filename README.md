## Projects

### 1. IT Help Desk Ticket Management System

[View Project](https://github.com/Crodas012/data-science-portfolio/blob/main/It_helpdesk_ticket_management.ipynb)

Created a sample help desk ticket management database using Python and TinyDB. Managed user and support ticket records, performed CRUD operations, and used queries to filter tickets by priority, status, and issue type. Included duplicate ticket ID checks and basic reporting.

**Tools:** Python, TinyDB, Jupyter Notebook

### 2. Food Delivery Time Analysis

[View Project](https://github.com/Crodas012/data-science-portfolio/blob/main/Food_delivery_time_eda.ipynb)

Analyzed 1,000 food delivery records to identify factors associated with delivery times. Checked data quality, explored relationships between variables, and created visualizations to examine delivery distance, traffic, weather, and preparation time. Used correlation analysis to identify factors associated with longer deliveries.

**Tools:** Python, Pandas, Matplotlib, Seaborn

### 3. Telecom Customer Churn Analysis

[View Project](https://github.com/Crodas012/data-science-portfolio/blob/main/Telecom_customer_churn_analysis.ipynb)

Analyzed 10,000 telecom customer records using PySpark and Scikit-learn. Performed data cleaning, feature engineering, and exploratory analysis. Built Logistic Regression models and used K-means clustering to examine customer groups. Compared accuracy, precision, recall, and F1-score to evaluate model performance and identify limitations.

**Tools:** Python, PySpark, Scikit-learn

### 4. Hotel Review Sentiment Analysis

[View Project](https://github.com/Crodas012/data-science-portfolio/blob/main/Hotel_Review_Sentiment_Analysis.ipynb)

Built a sentiment classification model to analyze positive and negative hotel reviews. Cleaned and processed text data, applied TF-IDF, and trained a Logistic Regression model. Evaluated performance using validation and test datasets, achieving 87.86% test accuracy.

**Tools:** Python, Natural Language Processing (NLP), TF-IDF, Scikit-learn

### 5. Medicare Part D Spending Analysis

[View Project](https://github.com/Crodas012/data-science-portfolio/blob/main/Medicare_Part_D_EDA.ipynb)

Explored Medicare Part D prescription drug spending data using Python. Examined spending distributions, prescription claims, missing values, outliers, and correlations. Used visualizations and initial feature engineering to investigate spending patterns and high-cost medications.

**Tools:** Python, Pandas, Matplotlib, Seaborn
